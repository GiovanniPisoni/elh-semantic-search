# Precision@K micro-benchmark — workflow

This micro-benchmark measures retrieval quality (Precision@5, Recall@5, F1@5) for the two semantic RAG tools (`search_descriptions`, `search_reviews`) on 10 hand-curated English queries with human-annotated ground truth. The flow is three steps: (1) run `python -m scripts.eval.precision_at_k_extract` to fetch top-10 candidates per query into `benchmarks/runs/precision_at_k_candidates.jsonl` and a scannable companion `precision_at_k_candidates_human.txt`; (2) open `benchmarks/queries/precision_at_k_queries.yaml` and fill each query's `relevant_source_ids` with the IDs from the candidates file that genuinely answer the query; (3) run `python -m scripts.eval.precision_at_k_compute` to write the final report to `precision_at_k_semantic.md`. Interpret the numbers as *indicative* — small sample size (n=10), single annotator, and recall bounded to the top-10 mean these are sanity checks, not statistical claims; treat per-query failures as the most actionable signal.
